# Developing an Artificial Intelligence System for Early Detection of Depression Risk from Social Media Messages
## 📌 Overview
This project develops a machine learning model and a school-based web application for early detection of depression risk using text from social media and DASS assessments. The system screens depression levels (0–4) and provides both individual and group-level analytical results for school monitoring.

## 🚀 Key Contributions

Built multiple ML models for depression classification: Logistic Regression, Random Forest, Naïve Bayes, SVM, KNN, and LSTM.
Integrated text-based screening with DASS-based psychological assessments.
Developed a web application for real-time depression monitoring in schools.
Conducted user satisfaction evaluation, with high satisfaction scores on usability and design.

## 🏆 Model Performance 

The **LSTM model** achieved the best performance, with:

| --- | :-: | 
| Accuracy | **0.66** |
| Precision | **0.63** | 
| Recall | **0.77** | 
| F1-score | **0.63** |
